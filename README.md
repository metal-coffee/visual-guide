# visual-guide

Python開発に関する図解資料をまとめたリポジトリです。

## 構成

現在の資料は `python_development` 配下にまとまっています。

- `environment`
  - Python開発環境に関する図解
- `package-management`
  - パッケージ管理やプロジェクト構成に関する図解
- `testing`
  - テストに関する図解
