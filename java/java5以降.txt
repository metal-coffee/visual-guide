Virtual Threadは「文法」というより並行処理機能ですが、現在のJavaを理解するなら重要です。



① コレクションの書き方
② nullの扱い
③ 条件分岐
④ オブジェクト定義

⑦ 例外・リソース管理

という用途別に覚えた方が実務向けです。
私なら、Java 5あたりからのキャッチアップ用に次の 8章構成 にします。
1. Generics・拡張for・enum
2. try-with-resources・diamond
3. LambdaとFunctional Interface
4. Stream API
5. Optional
6. var・switch式・text block
7. record・pattern matching・sealed
8. 現代Javaの実務コードを読む練習
この順番なら、Spring Bootのコードを読む能力にも直接つながります。
特に Lambda / Stream / Optional / record / pattern matching の5つを重点的にやれば、Java 5世代からでもかなり追いつけます。
